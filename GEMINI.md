## 🏛️ Летопись и Идеология «Школы Христа» (School of Christ International)
1. **Основатель**: Преподобный Берт Кленденнен (B. H. Clendennen, 1922–2009). 55 лет рукоположенного служения, основатель Victory Temple в Бомонте, Техас (1956).
2. **Зарождение Видения (1971, Заир)**: В 1971 г. во время масштабной евангелизации в Киншасе Берт Кленденнен увидел, что массовые крусейды без глубокой подготовки местных служителей не дают долговечных плодов. Родился ключевой принцип: *«Обучать и посылать местного коренного жителя к своему собственному народу»*.
3. **Модель «Духовного Boot Camp»**: По образу 12-недельной интенсивной подготовки Морской Пехоты США (US Marine Corps): 3 месяца полного погружения в молитву и Слово Божье. Молитва — обязательный класс, ибо *«без молитвы библейская школа — лишь доктрина»*.
4. **Прорыв в СССР / СНГ (1991–1992)**: В октябре 1991 г. Берт Кленденнен посетил Москву. В декабре 1991 г. ушел с поста старшего пастыря Victory Temple, чтобы посвятить себя миссионерству. 1 октября 1992 г. была открыта первая Международная Пятидесятническая Библейская Школа в Москве (102 студента). Служение охватило весь бывший СССР (Россия, Украина, Армения, Грузия, Кыргызстан, Балтия, Пермь, Ростов).
5. **Глобальный охват**: Охвачено более 160 стран мира, подготовлены десятки тысяч служителей, открыты тысячи церквей.
6. **Шехина Миссия Казахстан**: Продолжает эту эстафету веры в Казахстане и Центральной Азии, подготавливая миссионеров и пастырей, объединяя духовную истину, молитвенное дерзновение и современные технологии («Цитадель Духа»).

## ⚡ КРИТИЧЕСКИ ВАЖНО: Установка зависимостей
Так как в проекте используется **React 19** поверх **Docusaurus 3** (у которого в `peerDependencies` прописан React 18), стандартный `npm install` будет завершаться ошибкой конфликта зависимостей (`ERESOLVE`).

**Команда для установки зависимостей (строго обязательно):**
```bash
npm install --legacy-peer-deps
```
> ⚠️ **НЕ запускайте** чистый `npm install`, `yarn` или `pnpm` без флага `--legacy-peer-deps` (или `--force`).

## 🛠 Полезные команды разработки

| Команда | Описание |
| :--- | :--- |
| `npm install --legacy-peer-deps` | Установка всех зависимостей с обходом peer-conflicts |
| `npm run start` | Запуск локального dev-сервера Docusaurus на `http://localhost:3000` |
| `npm run build` | Производственная сборка проекта в папку `build/` |
| `npm run serve` | Просмотр собранного production-сайта локально |
| `npm run clear` | Очистка кэша Docusaurus |
| `npm run typecheck` | Проверка типов TypeScript |

## 📁 Структура проекта
- `docs/` — Основные документационные материалы, исторические летописи Школы Христа и учебные статьи Shekinah Mission.
- `blog/` — Записи Блога Мыслей и свидетельства жизни.
- `src/` — Пользовательские компоненты React, страницы (`src/pages`), стили (`src/css/custom.css`).
- `static/` — Статические ресурсы (изображения, иконки).
- `docusaurus.config.ts` — Главная конфигурация Docusaurus (SEO, навбар, футер, плагины).
- `sidebars.ts` — Конфигурация бокового меню документов.
