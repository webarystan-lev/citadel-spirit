## ⚙️ ТЕХНИЧЕСКИЙ УСТАВ РАЗРАБОТКИ (`citadel-spirit`)

- **Движок**: Docusaurus 3.9.2 + React 19.0.0
- **Установка зависимостей**: `npm install --legacy-peer-deps` (строго обязательно из-за peer-conflicts с React 18).
- **Сборка**: `npm run build`
- **Проверка типов**: `npm run typecheck`
- **Конфигурация `.npmrc`**: Установлен параметр `legacy-peer-deps=true` для бессбойного авто-деплоя на Cloudflare Pages / Vercel / Netlify.
