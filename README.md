Цифровой портал **Цитадель Духа** (`citadel-spirit`) — это единый информационно-просветительский центр **Shekinah Mission Kazakhstan**, созданный для подготовки миссионеров, пастырей и служителей на основании Евангелия Иисуса Христа. Портал хранит духовное наследие, учебные материалы, исторические летописи и архивы служения.

Проект является продолжением всемирного служения Преподобного Берта Кленденнена (Rev. B. H. Clendennen, 1922–2009) — **«Школа Христа» ([The School of Christ International](https://schoolofchrist.org/history/))**.

## 📜 Духовное Основание и Летопись «Школы Христа»

### ✝️ Преподобный Берт Кленденнен (1922–2009)
* **55 лет** рукоположенного пастырского и миссионерского служения.
* В ноябре 1956 года основал церковь **Victory Temple** в Бомонте (Техас, США), ставшую духовным центром поддержки мировых миссий.
* Проповедовал Слово Божье в Танзании (1967), Иране (1968), Вьетнаме (1968–1975), Заире (1971–1980-е), Болгарии, Румынии и Югославии.

### 💡 Откровение в Заире (1971)
Во время масштабного евангелизационного крусейда в Киншасе (Заир, 1971 г.) тысячи людей приняли Христа. Вернувшись через год, Берт Кленденнен увидел, что без подготовленных местных служителей плоды массовых крусейдов угасают.
* В молитве родился ключевой принцип: **«Обучать и посылать местного коренного жителя к своему собственному народу»**.
* **Духовный «Boot Camp»**: По образу 12-недельной интенсивной подготовки Морской Пехоты США (US Marine Corps) была создана 3-месячная программа полного погружения в молитву и Слово Божье. 
* **Молитва — обязательный класс**: *«Без молитвы библейская школа — лишь сухая доктрина. Жизнь рождается только в молитве»*.

### 🌏 Прорыв в СНГ и Всемирный Охват (1991–1992+)
* **1 октября 1992 года**: Открытие первой Международной Пятидесятнической Библейской Школы Христа в Москве (102 студента).
* Служение мгновенно охватило страны бывших республик (Казахстан, Россия, Украина, Армения, Грузия, Кыргызстан, Балтия).
* На сегодняшний день **The School of Christ International** охватила более **160 стран мира**, подготовив десятки тысяч пастырей и открыв тысячи церквей.

### 🇰🇿 Shekinah Mission Kazakhstan
В Казахстане и Центральной Азии **Shekinah Mission** продолжают эту эстафету веры, подготавливая миссионеров и пастырей, объединяя фундаментальные духовные истины Евангелия и современные веб-технологии.
* Подробнее с официальной историей служения можно ознакомиться на [schoolofchrist.org/history/](https://schoolofchrist.org/history/).

## ⚡ Важно: Конфликт версий React 19 & React 18

Проект осознанно построен на **React 19**, в то время как текущая версия Docusaurus v3 объявляет в своих `peerDependencies` поддержку React 18.

### Почему это важно?
При выполнении стандартных команд `npm install` или `npm ci` менеджер пакетов npm блокирует установку с ошибкой `ERESOLVE` (peer dependency conflict).

### 🛠️ Решение в проекте:
1. В корень проекта добавлен файл `.npmrc` с параметром `legacy-peer-deps=true`.
2. При ручной установке зависимостей **строго обязательно** использовать флаг `--legacy-peer-deps`:
   ```bash
   npm install --legacy-peer-deps
   ```

### 🔄 Метод отката на React 18 (при необходимости):
Если вам потребуется вернуть проект на классический React 18, выполните следующую команду в терминале:
```bash
npm install react@18.3.1 react-dom@18.3.1 --legacy-peer-deps
```
После этого `package.json` вернется на React 18 и конфликт `peerDependencies` с Docusaurus полностью исчезнет.

## 🚀 Быстрый Старт и Локальное Разворачивание

### 1. Клонирование репозитория
```bash
git clone https://github.com/webarystan-lev/citadel-spirit.git
cd citadel-spirit
```

### 2. Установка зависимостей
```bash
npm install --legacy-peer-deps
```

### 3. Запуск dev-сервера
```bash
npm run start
```
Сервер запустится по адресу [http://localhost:3000](http://localhost:3000) с автоматической перезагрузкой при изменениях (Hot Reload).

## 🛠️ Доступные Команды

| Команда | Описание |
| :--- | :--- |
| `npm install --legacy-peer-deps` | Установка всех зависимостей с учетом React 19 |
| `npm run start` | Запуск локального сервера разработки Docusaurus (`http://localhost:3000`) |
| `npm run build` | Компиляция стилей Tailwind и сборка статического сайта в папку `build/` |
| `npm run serve` | Локальный предпросмотр готовой продакшн-сборки из папки `build/` |
| `npm run clear` | Полная очистка кэша Docusaurus |
| `npm run typecheck` | Проверка типов TypeScript во всем проекте |
